# Graduated hints

Try the problem before opening each hint. Stop when you can continue independently.

## Hint 1

Hint 1: Graph ek tree hai jisme koi cycle nahi hai. Agar hum city 0 ko root maan lein, toh sabhi paths root ki taraf aane chahiye.

## Hint 2

Hint 2: Root (city 0) se start karke pura tree traverse karne ke liye aapko edges ko bidirectional banana padega.

## Hint 3

Hint 3: Jab aap root se bahar move karte ho aur edge bhi usi direction me ja rahi ho, iska matlab wo root se door ja rahi hai aur usko reverse karna padega.
