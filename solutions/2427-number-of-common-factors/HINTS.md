# Graduated hints

Try the problem before opening each hint. Stop when you can continue independently.

## Hint 1

Common factor kabhi bhi min(a, b) se bada nahi ho sakta.

## Hint 2

Think about Greatest Common Divisor (GCD). Kya a aur b ke common factors aur unke gcd ke factors mein koi relation hai?

## Hint 3

Har common factor gcd(a, b) ko bhi divide karta hai, toh bas gcd(a, b) ke divisors count kar lo.
